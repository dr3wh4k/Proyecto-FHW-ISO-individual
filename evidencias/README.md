# Evidencias

Guardar aquí capturas y salidas de comandos que demuestren la instalación y las pruebas.

- Nombrar archivos de forma descriptiva: `proxmox-red-2026-11-09.png`.
- Añadir en el documento correspondiente una explicación de qué demuestra cada evidencia.
- Ocultar contraseñas, tokens, claves, datos personales y direcciones que no deban publicarse.
- No subir exportaciones completas de configuración si contienen secretos.
